## 책임

이 컴포넌트는 clawket CLI 안에서 "로컬 데몬 프로세스를 돌보는 역할"을 맡는다. 사람이 직접 부르는 `clawket daemon start|stop|status|restart|log` 명령의 실제 동작을 구현하고, 동시에 데몬이 필요한 다른 CLI 명령(특히 MCP 서버 기동)이 데몬을 자동으로 깨우는 길도 제공한다.

핵심 책임은 다음과 같다.

- **백그라운드 기동**: 데몬을 떼어내(detach) 백그라운드로 띄운다. 세션 시작 훅이 동기적으로 기동을 호출해도, 데몬이 떠 있는 동안 호출자가 함께 멈추지 않도록 즉시 손을 뗀다. 기동 후 짧게 준비 상태를 기다려 "떴다/뜨는 중" 신호를 돌려준다.
- **생존 판정**: "프로세스 ID가 존재한다"가 아니라 "데몬이 실제로 응답하는가"를 기준으로 삼는다. 강제 종료 후 흔적(좀비 프로세스)만 남으면 ID 검사는 통과해버려 죽은 데몬을 살아 있다고 오판하게 되는데, 이 컴포넌트는 소켓에 실제로 연결을 시도해 그 함정을 피한다.
- **종료(단계 상승)**: 먼저 점잖게 종료를 시도하고, 정해진 시간 안에 멈추지 않으면 강제 종료로 단계를 올린다. 강제 종료 후에는 남은 흔적 파일(프로세스 ID·포트 기록)을 정리해 다음 기동이 깨끗하게 새 데몬을 띄울 수 있게 한다.
- **상태·재시작·로그**: 데몬에 상태를 묻고, 종료 후 다시 기동하는 재시작을 묶어 처리하며, 데몬 로그 파일의 마지막 줄들을 보여주거나 실시간으로 따라 본다.
- **자동 기동(autostart)**: 데몬이 필요한 CLI 명령이 호출될 때 데몬이 안 떠 있으면 알아서 띄운다. 이때 여러 호출이 동시에 기동을 시도하지 않도록 파일 잠금으로 한 번에 하나만 기동하게 조율하고, 첫 실행 시 모델 로딩 등으로 시간이 걸려도 곧장 실패로 처리하지 않는다.

## 경계와 의존

이 컴포넌트는 CLI 바이너리(`component.cli`)의 일부로 컴파일되는 내부 모듈이다. 돌보는 대상은 같은 기기의 clawketd 데몬 프로세스(`component.daemon`)이며, 프로세스를 띄우고 신호를 보내는 운영체제 수준의 동작을 직접 수행한다.

데몬 실행 파일과 소켓·프로세스 ID·로그 파일의 위치는 스스로 정하지 않고 경로 해석 컴포넌트(`component.paths`)가 제시하는 후보를 따른다. 사람을 향해서는 데몬 관리 명령 묶음(`endpoint.cli-daemon`)으로 노출된다. 데몬 프로세스를 켜고 끄는 토대이므로 모든 상태가 로컬에 머무는 local-first 동작(`platform.local-first`)을 떠받친다.

## 통신 패턴

데몬과의 "통신"은 HTTP 요청이 아니라 프로세스 제어에 가깝다. 데몬을 자식 프로세스로 띄우되 곧바로 부모와의 연결을 끊어(reparent) 독립적으로 살게 하고, 종료할 때는 운영체제 신호를 보낸다. 생존 여부만큼은 데몬의 소켓에 실제로 붙어보는 방식으로 확인한다. 기동 환경은 환경 변수로 조정할 수 있어, 자동 기동을 끄거나 데몬 실행 파일 경로를 지정하는 식의 운영 제어가 가능하다.

## 하위 서브패키지 (책임 단위)

- **명령형 관리**: 사람이 부르는 start/stop/status/restart/log 동작 — 기동·종료(강제 종료 단계 상승 포함)·상태·로그 처리.
- **자동 기동**: 데몬이 필요한 명령이 호출될 때 잠금으로 한 번에 하나만 기동하도록 조율하며 데몬이 응답할 때까지 기다리는 동작.
