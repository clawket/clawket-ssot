## 책임

이 컴포넌트는 사이트의 모든 글자를 방문자 언어에 맞춰 공급한다. 영어·한국어·일본어·중국어(간체/번체)를 비롯한 20개 언어를 지원하며, 화면에 표시되는 카피는 하드코딩하지 않고 전부 이 엔진의 카피 사전에서 가져온다.

세 가지 일을 한다. 첫째, 어떤 언어를 보여 줄지 정한다 — 방문자가 명시한 값(주소의 언어 파라미터)이 가장 우선이고, 다음으로 브라우저에 저장된 직전 선택, 마지막으로 브라우저가 알려 주는 사용 언어를 차례로 본다. 둘째, 고른 언어를 문서에 적용한다 — 페이지의 언어 표시와 글쓰기 방향(아랍어 같은 우→좌 언어 포함)을 맞춘다. 셋째, 카피 안에 들어 있는 코드 조각 표시를 안전하게 렌더해 본문 가운데 명령어·식별자가 코드 스타일로 보이게 한다.

언어 선택은 방문자 단위로 기억된다. 한 번 고르면 브라우저에 저장되어 다음 방문에도 같은 언어로 열린다.

## 경계와 의존

외부 i18n 라이브러리에 의존하지 않는 자체 구현이다. 카피가 빠진 키가 있으면 기본 언어(영어) 값으로, 그것도 없으면 키 이름 자체로 안전하게 떨어지도록 되어 있어, 일부 언어 번역이 비어 있어도 화면이 깨지지 않는다.

문서 영역(시작하기·워크플로우 등 4개 문서 페이지)은 현재 이 엔진을 거치지 않고 영어 단일 언어로 작성되어 있다. 다국어가 적용되는 곳은 주로 홈 화면이다.

번역 동기화는 별도 CI 게이트가 감시한다. 원문과 번역본 사이의 불일치(drift)를 검사하는 워크플로가 본체 저장소의 기준 스크립트를 가져와 돌린다.

## 통신 패턴

네트워크 통신 없이 클라이언트 안에서만 동작한다. 언어 선택값을 브라우저 저장소에 읽고 쓰는 것이 외부 상호작용의 전부다.

## 하위 서브패키지 (책임 단위)

세 부분으로 나뉜다. 첫째는 지원 언어 목록과 브라우저 언어 협상 규칙을 담는 부분, 둘째는 언어별 카피 사전, 셋째는 앱 전체에 현재 언어와 번역 함수를 공급하고 코드 조각을 렌더하는 공급자 부분이다.
