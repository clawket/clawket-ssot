## 책임

UI 패키지는 데스크탑 화면을 짜는 데 필요한 시각 부품을 한 묶음으로 제공한다. 기본 입력 요소(버튼·입력칸·라벨·도움말 텍스트·폼 필드)부터, 작업관리 화면에 특화된 부품까지 포함한다. 작업 상태를 나타내는 상태 표시, 태스크가 요구하는 모델 등급을 보여 주는 티어 표식, 어떤 에이전트가 일했는지 알려 주는 에이전트 태그, 근거를 칩 형태로 보여 주는 근거 칩, 화면 골격을 잡아 주는 앱 셸, 플랜·유닛·태스크 구조를 나무 형태로 펼치는 플랜 트리, 태스크 한 건을 카드로 요약하는 태스크 카드, 한 태스크의 머리말·본문·구획을 짜는 태스크 상세, 빠른 이동을 돕는 명령 팔레트, 접히는 필터 등이 들어 있다.

부품과 함께 테마도 제공한다. 현재 테마를 읽고 바꾸고, 저장된 선호를 불러오고, 실제 적용되는 테마(라이트/다크)를 알려 주는 도구를 노출해 화면 전체의 색·톤을 일관되게 맞춘다.

이 부품들은 별도 카탈로그(Storybook)로 묶여 있어, 화면에 붙이기 전에 부품 하나하나를 떼어 놓고 모양과 상태별 변형을 확인할 수 있다.

## 경계와 의존

이 패키지는 순수한 화면 부품 묶음이다. 데몬이나 데이터에 직접 닿지 않으며, 상태를 받아 그리는 일만 한다. 데이터를 어떻게 불러오고 어떤 동작을 거는지는 부품을 쓰는 쪽(렌더러)이 결정한다. 따라서 이 패키지는 데스크탑 렌더러(`component.renderer`)에 화면 부품을 공급하는 위치이고, 렌더러는 이 부품들을 가져다 화면을 조립한다.

React 19 환경에서 쓰이도록 맞춰져 있으며, 스타일은 Tailwind 기반 디자인 토큰과 base 스타일을 함께 내보내 색·간격 같은 디자인 변수를 통일한다.

## 통신 패턴

UI 패키지는 네트워크 통신을 하지 않는다. 외부와의 소통은 컴포넌트의 입력(속성)과 출력(콜백)으로만 이뤄지며, 데이터 흐름은 전적으로 이 패키지를 쓰는 렌더러가 책임진다.

## 하위 서브패키지 (책임 단위)

- 기본 입력 부품: 버튼·입력칸·라벨·도움말 텍스트·폼 필드.
- 작업관리 표식 부품: 상태 표시·티어 표식·에이전트 태그·근거 칩.
- 레이아웃·구조 부품: 앱 셸·플랜 트리·태스크 카드·태스크 상세.
- 탐색·필터 부품: 명령 팔레트·접히는 필터.
- 테마: 라이트/다크 테마 읽기·전환·저장 도구와 디자인 토큰·base 스타일.
