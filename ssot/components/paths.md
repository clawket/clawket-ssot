## 책임

이 컴포넌트는 CLI 안에서 "모든 파일·디렉터리·소켓 위치를 계산하는 단일 출처"다. 다른 모듈들이 위치를 직접 추측하지 않고 이곳에 물어보게 함으로써, 데이터가 한 곳에 모이고 데몬을 항상 같은 자리에서 찾도록 보장한다.

계산해 주는 것들은 다음과 같다.

- **표준 디렉터리**: 캐시·데이터·설정·상태 디렉터리. 기본은 운영체제의 XDG 표준 위치 아래 clawket 전용 폴더이고, 사용자가 CLAWKET_* 환경 변수로 직접 지정하면 그쪽을 우선한다(격리 환경·테스트·맞춤 배치를 위해).
- **데몬 통신·프로세스 파일**: 데몬과 붙을 소켓 경로(환경 변수로 재정의 가능), 데몬의 프로세스 ID 파일, 포트 기록 파일의 위치.
- **데몬 실행 파일 후보**: 데몬 바이너리를 어디서 찾을지 우선순위가 매겨진 후보 목록을 만든다. 플러그인 설치 배치, 같은 폴더(형제) 배치, XDG 설치 배치 순으로 후보를 제시하며, 각 후보에는 진단이 "어느 자리에서 찾았는지" 보여줄 라벨이 붙는다.
- **경로 겹침 불변식**: 어떤 경로가 Claude Code 플러그인 디렉터리 아래로 들어가는지 판별하는 규칙을 제공한다. 데몬은 자체적으로 같은 규칙을 런타임 가드로 강제하고, CLI 쪽에서는 이 규칙으로 진단(doctor)이 동일한 상태를 보고할 수 있게 한다.

## 경계와 의존

이 컴포넌트는 CLI 바이너리(`component.cli`)의 일부로 컴파일되는 가장 아래쪽 토대 모듈이다. 자신은 다른 컴포넌트를 호출하지 않고, 오히려 데몬 통신 클라이언트·데몬 수퍼바이저·진단 엔진 등 여러 상위 모듈이 이 컴포넌트가 계산한 위치를 가져다 쓴다. 외부에 API를 제공하거나 외부 API를 호출하지 않는, 순수한 위치 계산 계층이다.

모든 상태가 사용자 로컬의 정해진 자리에 머물도록 위치를 정의하므로 local-first 동작(`platform.local-first`)의 토대가 되며, 데이터가 플러그인 디렉터리와 분리되도록 지키는 불변식의 출처이기도 하다.

## 통신 패턴

외부와 직접 통신하지 않는다. 환경 변수와 운영체제의 홈·XDG 위치를 읽어 경로를 조립할 뿐이다. 다만 데몬 실행 파일 후보를 계산할 때는 현재 실행 중인 CLI 바이너리의 실제 위치를 기준으로 삼아, 설치 형태가 다른 환경에서도 데몬을 제대로 찾아내도록 한다.

## 하위 서브패키지 (책임 단위)

CLI 안의 단일 모듈로, 별도의 하위 패키지로 쪼개지지 않는다. 표준 디렉터리 해석, 데몬 관련 파일 경로, 데몬 바이너리 후보, 경로 겹침 판정이라는 책임들이 한 모듈 안에 모여 있다.
