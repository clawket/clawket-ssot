## 화면 목적

clawket.dev 의 첫 페이지다. 검색이나 링크를 타고 처음 들어온 사람이 "Clawket이 무엇인가"를 빠르게 파악하도록 설계되어 있다. 핵심 메시지는 "LLM 코딩 에이전트의 작업을 구조화된 계약으로 묶고, 검증 가능한 근거(--evidence) 없이는 작업을 완료(done)로 표시하지 못하게 막는 로컬 우선 도구"라는 것이다. 방문자는 이 화면에서 제품을 이해한 뒤, 설치하거나(상단 CTA), 소스 코드를 보거나(GitHub), 문서로 더 깊이 들어간다(헤더의 Docs 링크).

## UI 요소 / 입력 필드

위에서 아래로 다음 블록이 한 컬럼으로 쌓인다.

- 상단 바: 제품 버전 라벨, 문서로 가는 "Docs" 링크, 언어 전환기.
- 히어로: 두 줄짜리 헤드라인과 리드 문장(리드에는 본문 중간에 코드 스타일로 강조되는 키워드가 포함된다).
- 주 행동 버튼(CTA) 둘: "설치"(GitHub 플러그인 레포로 이동)와 "GitHub"(조직 페이지로 이동). 둘 다 외부 링크다.
- 데모 섹션: 자동재생·음소거·반복·인라인 재생되는 약 12초 데모 영상. 포스터 이미지가 먼저 뜨고, webm 우선·mp4 폴백으로 재생된다. 스크린리더용 설명 라벨이 붙는다.
- "강제 흐름" 섹션: 번호가 매겨진 3개의 단계 카드(Step 1·2·3)로 Clawket이 작업을 어떻게 강제하는지 요약한다.
- "특징" 섹션: 3개의 특징 카드.
- "아키텍처" 섹션: 한 단락짜리 구조 설명(코드 스타일 강조 포함).
- 푸터: 한 줄 텍스트.

사용자 입력 필드는 없다. 유일한 상호작용은 링크/버튼 클릭과 언어 전환이다.

## 표시 데이터 / 호출 API

이 화면이 보여 주는 모든 텍스트(헤드라인·리드·단계·특징·아키텍처·푸터·버튼 라벨)는 백엔드 API가 아니라 프런트엔드에 내장된 다국어 사전에서 온다. 현재 선택된 로케일에 맞는 문구가 주입되며, 언어 전환기로 즉시 바뀐다. 데몬이나 데이터베이스를 호출하지 않는 순수 정적 마케팅 화면이므로 호출하는 endpoint 가 없다. 데모 영상과 포스터 이미지는 사이트에 동봉된 정적 자산이다.

## 상태 / 엣지케이스

- 정적 콘텐츠라 로딩/에러 상태가 별도로 없다. 영상이 재생되지 않는 환경에서는 포스터 이미지가 그대로 남는다.
- 다국어: 선택 언어에 해당 문구가 없으면 사전의 폴백 체인을 따라 다른 언어로 대체된다.
- 모든 CTA는 외부 GitHub로 나가는 링크이므로 인증·세션 분기가 없다.
