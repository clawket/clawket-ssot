## 사용자가 할 수 있는 일
태스크는 Clawket에서 사람·에이전트가 직접 손대는 유일한 원자적 작업 단위다. 이 기능은 그 태스크의 거의 모든 것을 책임진다 — 만들고, 상태를 옮기고(todo→진행중→완료/취소, 외부 의존 시 차단), 여러 개를 한꺼번에 고치고, 본문을 덧붙이고, 검색하고, 비슷한 태스크를 찾고, 배치별 검증 통계를 보고, 부모/자식 트리를 위아래로 훑고, 코드가 계획에서 얼마나 벗어났는지(드리프트) 확인한다. 핵심은 "전이마다 게이트가 있다"는 점이다. 태스크를 만들 때는 실행 계약(봉투)의 필수 필드(의도·프롬프트 템플릿·성공 기준)가 채워져 있어야 하고, 사이클 배정이 강제되며, 시나리오 ID·배치 ID·증거 길이가 형식 검증을 받는다. 진행중으로 옮길 때는 봉투의 전제조건을, 완료로 옮길 때는 사후조건을 실제 상태에 대고 평가해 위반하면 막는다. 사용한 모델 티어가 선언과 다르면 에스컬레이션 사유를 반드시 적어야 한다.

## 행위
- 목록 조회: 유닛·플랜·사이클·상태·담당·에이전트·부모·티어·QA 상태·시나리오·배치 등 다양한 기준으로 거르고, 개수 제한·건너뛰기로 페이지를 나눠 본다.
- 생성: 제목과 유닛, 그리고 사이클 배정이 필수다. 작업 디렉터리를 주면 유닛을 자동 추론할 수 있으나 사이클은 항상 명시해야 한다. 봉투를 함께 주면 필수 필드 검증, 비밀값/고엔트로피 거부, 계획 시점 커밋 자동 채움, 서명을 한 트랜잭션 안에서 원자적으로 처리해 반쪽짜리 태스크가 남지 않게 한다.
- 단건 조회·수정·삭제: 하나를 보고 고친다. 삭제는 초안 플랜 아래의 todo 태스크만 실제로 지우고, 그 외에는 취소 상태로 바꾸고 시스템 코멘트를 남겨 이력을 보존한다.
- 상태 전이 게이트: 진행중 전환 시 전제조건, 완료 전환 시 사후조건을 봉투에서 평가하며 위반 시 충돌로 거부하고 어긋난 조건을 함께 돌려준다. 취소 전환은 사후조건을 평가하지 않는다.
- 본문 덧붙이기·코멘트 동봉: 본문에 텍스트를 추가하거나 수정과 동시에 코멘트를 달아 감사 이력을 남긴다.
- 일괄 수정: 여러 태스크 ID에 같은 필드 변경을 한 번에 적용한다.
- 검색: 키워드(FTS), 의미(벡터), 둘을 합친 하이브리드, 그리고 봉투 내용만 노리는 봉투 전용 모드를 지원한다.
- 통계: 배치 ID 기준으로 통과·결함·시나리오오류 개수를 집계한다.
- 유사 태스크: 한 태스크를 시드로 의미적으로 가까운 태스크를 찾는다.
- 트리 탐색: 조상·후손·서브트리를 깊이 제한과 함께 조회한다. 서브태스크 생성과 분해 제안으로 트리를 키운다.
- 드리프트: 봉투의 계획 시점 커밋과 현재 상태를 비교해, 범위 안에서 바뀐 파일 수에 따라 드리프트 정도를 분류한다.
- 리스(lease) 잠금: 태스크에 세션 단위 점유 잠금을 걸고 갱신·해제해 여러 에이전트의 동시 작업 충돌을 막는다.

## 시스템 흐름
요청은 데몬의 태스크 HTTP 라우트로 들어온다. 생성에서는 (1) 사이클 필수 검사, (2) 봉투 필수 필드 검증, (3) 비밀값/고엔트로피 거부를 모두 변경 전에 끝내고, 통과하면 태스크 INSERT와 봉투 서명을 하나의 트랜잭션으로 커밋해 중간 실패가 고아 데이터를 남기지 않게 한다. 수정에서는 상태 전이 직전에 봉투의 전제/사후조건을 평가하고, 티어 변경 시 에스컬레이션 사유 유무를 검사한 뒤 변경을 적용하며, 변경·cascade 완료 이벤트를 발행한다. 검색·유사·통계는 키워드/벡터 엔진과 집계 쿼리를 호출해 결과를 돌려주고, 드리프트는 등록된 작업 디렉터리에서 두 커밋 사이의 변경 파일을 범위와 대조해 등급을 매긴다.

## 어디에 구현되어 있나
데몬의 태스크 라우트 계층(`daemon/src/routes/tasks.rs`)이 목록·생성(검증·원자적 트랜잭션 포함)·조회·수정(전이 게이트·티어 게이트 포함)·삭제(초안 todo 하드삭제 vs 취소 보존), 본문 덧붙이기, 일괄 수정, 검색(키워드/의미/하이브리드/봉투), 배치 통계, 유사 검색, 봉투 조회·검증·이력, 분해·서브태스크, 조상·후손·서브트리, 드리프트, 리스 잠금까지의 HTTP 표면과 게이트 로직을 담는다. 사람·에이전트는 CLI(태스크 명령)와 웹 대시보드를 통해 호출한다.
