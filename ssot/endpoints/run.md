## 정의
한 태스크가 실제로 "한 번 돌았다"는 사실을 기록으로 남기는 명령 묶음이다. 어떤 에이전트가 언제 시작해 언제 끝났고 그 결과가 성공이었는지 실패였는지 취소였는지를 보존한다. 대부분 사람이나 에이전트가 손으로 부르지 않고, 태스크가 시작될 때 훅이 자동으로 실행 기록을 만든다. 이렇게 쌓인 기록은 나중에 타임라인 표시나 리플레이(실행 이력 재생)의 재료가 된다.

세부 동작은 네 갈래다.
- 시작: 특정 태스크에 대해 실행 기록을 연다. 어느 에이전트가 도는지(기본은 메인)와 세션 식별자(훅에서 넘어오는 내부 값)를 함께 남긴다.
- 종료: 열려 있는 실행 기록을 결과(성공/실패/취소)와 함께 닫고, 자유 형식의 마무리 메모를 붙일 수 있다.
- 조회·목록: 한 실행 기록을 펼쳐 보거나, 특정 태스크 또는 세션으로 걸러 목록을 본다.

## 요청 / 응답
- 시작에 보내는 것: 실행을 붙일 태스크, 실행 주체 에이전트, (훅이 채우는) 세션 식별자. 돌려받는 것: 새로 열린 실행 기록의 식별자.
- 종료에 보내는 것: 실행 기록 식별자, 결과(성공/실패/취소), 선택적 마무리 메모. 돌려받는 것: 종료 처리된 실행 기록.
- 목록에 보내는 것: 걸러낼 태스크나 세션. 돌려받는 것: 실행 기록 목록 — 각 항목은 어느 태스크·에이전트가 언제 시작·종료했고 결과가 무엇이며 메모가 무엇인지의 의미를 갖는다.

## 권한 / 제약
로컬 데몬을 통해 동작하며, 실제로는 사람보다 훅·에이전트가 호출하는 비중이 절대적이다. 종료 결과는 성공·실패·취소 셋 중 하나여야 한다. 시작 시 에이전트 이름과 세션 식별자는 환경 변수(에이전트 이름·세션 ID)에서 자동으로 채워질 수 있어, 훅이 명시적 인자 없이도 올바른 주체로 기록을 남긴다.

## provenance
명령 정의는 cli/src/main.rs의 Run 서브커맨드(상위 라우팅 150-155행, 액션 정의 1191-1229행)에 있고, 기록의 영속화는 데몬(component.daemon)이 SQLite에 수행한다. 코드가 사라져도 위 정책(훅 자동 생성, 성공/실패/취소 결과 모델, 태스크 귀속, 세션·에이전트 자동 채움)만으로 재구현 가능하다.
