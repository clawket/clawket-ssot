## 정의
프로젝트의 작업 디렉터리 안에 있는 위키성 마크다운 문서 한 개의 내용을 그대로 읽어오는 조회 기능이다. 웹 대시보드의 위키 화면에서 사용자가 문서 목록 중 하나를 클릭해 본문을 펼쳐 볼 때 호출된다. 데몬이 디스크의 실제 파일을 읽어 돌려주는 방식이므로, 별도의 저장소에 복제된 사본이 아니라 프로젝트 폴더의 현재 파일을 그대로 보여 준다.

## 요청 / 응답
요청에는 기준이 되는 작업 디렉터리 경로, 그 안에서의 상대 파일 경로, 그리고 어떤 프로젝트의 위키 설정을 따를지 가리키는 프로젝트 지정값을 함께 보낸다. 작업 디렉터리나 파일 경로가 비어 있으면 잘못된 요청으로 거절한다.

응답으로는 그 파일의 상대 경로, 확장자를 뗀 문서 이름, 마크다운 본문 전체, 본문이 마크다운 형식이라는 표시, 파일 크기, 마지막 수정 시각을 돌려준다.

## 권한 / 제약
- 읽을 수 있는 범위는 작업 디렉터리 자체와 그 프로젝트에 설정된 위키 폴더들로 한정된다. 프로젝트에 위키 폴더가 지정돼 있지 않으면 기본값으로 `docs` 폴더를 위키 루트로 본다.
- 요청 경로를 실제 파일 시스템 경로로 해석한 뒤, 그 결과가 허용된 위키 루트 중 하나의 하위에 있는지 검사한다. 상위로 거슬러 올라가는 경로 등으로 허용 범위를 벗어나면 접근을 금지한다(경로 탈출 방어). 이는 데몬이 임의 파일을 읽어 주는 통로가 되지 않도록 하는 제약이다.
- 존재하지 않는 파일이나 디렉터리를 가리키면 찾을 수 없음으로 응답한다.
- 읽기 전용이다. 이 기능으로 문서를 수정하거나 만들 수 없다.

## provenance
구현은 데몬의 위키 라우트(`daemon/src/routes/wiki.rs`)의 단일 파일 조회 핸들러에 있으며, 허용 위키 루트는 프로젝트 설정(없으면 `docs`)에서 결정된다. 제공 주체는 로컬 데몬이고, 호출 주체는 웹 대시보드의 위키 뷰다.
