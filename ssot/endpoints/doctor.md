## 정의
"내 Clawket 설치가 정상인가?"에 한 번에 답하는 종합 진단 명령이다. 운영자가 설치 직후나 문제가 의심될 때 실행하면, 여러 점검 항목을 차례로 돌면서 각각 정상/정보/오류로 표시하고, 그중 하나라도 오류가 있으면 명령 전체를 비정상 종료 코드로 끝내 자동화(설치 스크립트·CI)가 실패를 감지할 수 있게 한다. 사람이 읽는 텍스트 보고가 기본이며, 기계가 읽기 좋은 형식으로도 받을 수 있다.

점검하는 영역은 대략 다음과 같다: 환경 변수 오버라이드, 데이터/캐시/설정/상태/DB/소켓 등 경로 해석, 데몬 생존·버전·포트, 데이터베이스, 훅 등록, MCP 등록, 플러그인 설치, 호환성(스키마 버전), 다국어 로케일, 감사 로그, 데이터 손실 위험·보존 진단, 프로젝트 활성 상태, 레거시 데이터, 태스크의 tier 분포와 에스컬레이션 비율, 스킬, 그리고 경로 분리 불변식이다.

## 요청 / 응답
- 보낼 수 있는 것: 결과를 기계가 읽는 형식으로 받을지 여부, tier·에스컬레이션 집계를 특정 플랜의 태스크로만 한정할지, 에스컬레이션 비율 리포트(에스컬레이션 사유가 있는 태스크 수·비율을 tier별로 묶은 것)를 따로 낼지.
- 돌려주는 것: 항목별 점검 결과 묶음. 각 항목은 무엇을 검사했고 정상인지/주의인지/오류인지를 담는다. 데몬 항목은 가동 시간·PID·버전·소켓·포트 같은 부수 정보도 함께 보여준다.

## 권한 / 제약
로컬에서 그 사용자 계정으로 실행하는 읽기 전용 진단이며 상태를 바꾸지 않는다. 데몬이 꺼져 있을 때를 무조건 오류로 보지는 않는다 — 데몬 바이너리가 실제로 설치되어 있고 사용자가 소켓 경로를 따로 덮어쓰지 않은 정상 환경에서만 오류로 분류하고, 소켓 경로를 명시적으로 덮어쓴 격리/테스트 환경에서는 "데몬 없음이 의도된 상태"로 보고 정보 수준으로 낮춘다. 종료 코드 규칙은 자동화 게이트로 쓰이도록 "오류가 하나라도 있으면 실패"다.

## provenance
명령 정의와 옵션(기계형 출력·플랜 필터·에스컬레이션 리포트)은 CLI 진입점(`cli/src/main.rs`)에, 각 섹션의 점검 로직과 심각도 분류는 `cli/src/doctor.rs`에 있다. 제공 주체는 CLI 바이너리에 속한 진단(doctor) 컴포넌트다.
