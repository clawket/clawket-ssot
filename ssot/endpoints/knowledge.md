## 정의
사람과 LLM 에이전트가 프로젝트의 축적된 지식(결정 기록, 참고 문서, 메모, 명세 등)을 다루는 명령 묶음이다. 지식 항목을 새로 적고, 내용을 갱신하고, 더 이상 쓸모없는 항목을 지우며, 무엇보다 "예전에 우리가 무슨 결정을 했더라" 같은 질문에 답하기 위해 검색한다. 또한 프로젝트 폴더의 문서(docs)와 양방향으로 옮길 수 있어, 코드 저장소에 있는 문서를 지식 베이스로 끌어오거나 반대로 내보낼 수 있다. 위키처럼 부모-자식 계층을 갖고 있어 트리 형태로 전체 구조를 조망할 수도 있다.

세부 동작은 다음 갈래로 나뉜다.
- 생성: 제목·종류(문서/결정/참고/메모/명세 등)와 본문을 적고, 반드시 태스크·유닛·플랜 중 하나 이상에 붙여 어느 작업 맥락의 지식인지 명시한다. 부모 항목을 지정하면 위키 계층 아래로 들어간다.
- 조회·목록: 한 항목을 펼쳐 보거나, 특정 태스크/유닛/플랜/종류로 걸러 목록을 본다.
- 수정·삭제: 제목·본문·종류를 바꾸거나 항목을 제거한다. 수정 시 변경자를 남겨 감사 추적에 반영한다.
- 검색: 질의어로 찾되 키워드 전용·의미 전용·둘을 섞은 하이브리드 중 고를 수 있고, 종류로 좁히거나 결과 수를 제한한다. 기본은 하이브리드.
- 문서 동기화: 작업 디렉터리의 docs 폴더를 훑어 지식 항목으로 가져오거나(미리보기 가능), 반대로 항목을 docs 폴더로 내보낸다. 특정 플랜·유닛에 묶인 것만 골라 처리할 수 있다.
- 위키 트리: 부모-자식 관계를 재귀적으로 펼쳐 전체 숲 또는 특정 하위 트리를 평면 목록이나 들여쓰기 개요로 표시한다.

## 요청 / 응답
- 생성에 보내는 것: 제목, 지식 종류, 본문과 그 형식(마크다운·텍스트·코드), 붙일 작업 맥락(태스크/유닛/플랜 중 최소 하나), 선택적 부모 항목. 돌려받는 것: 만들어진 지식 항목의 식별자와 메타.
- 검색에 보내는 것: 질의어, 검색 방식(키워드/의미/하이브리드), 선택적 종류 필터, 결과 개수 상한. 돌려받는 것: 관련도 순으로 정렬된 지식 항목 목록 — 각 항목은 제목·종류·요약·관련도 점수 같은 의미를 갖는다.
- 목록·조회에 보내는 것: 걸러낼 맥락(태스크/유닛/플랜)이나 항목 식별자. 돌려받는 것: 항목 또는 항목 목록과 본문·메타.
- 문서 동기화에 보내는 것: 대상 작업 디렉터리, 묶을 플랜·유닛, 미리보기 여부. 돌려받는 것: 가져오거나 내보낸 항목 목록(미리보기면 실제 변경 없이 대상만).
- 위키 트리에 보내는 것: 선택적 하위 트리 루트, 플랜 한정, 들여쓰기 출력 여부. 돌려받는 것: 부모-자식 순서로 정렬된 지식 항목들.

## 권한 / 제약
로컬 데몬을 통해 동작하므로 같은 기기의 사람·에이전트가 호출한다. 생성 시 태스크·유닛·플랜 중 최소 하나에 붙여야 하는 것이 핵심 제약으로, 맥락 없는 떠도는 지식을 막는다. 검색의 의미·하이브리드 방식은 임베딩이 준비돼 있어야 의미가 있으며, 임베딩은 데몬이 항목 변경 시 자동 생성한다. 문서 가져오기의 미리보기 모드는 실제로 항목을 만들지 않고 대상만 보여준다.

## provenance
명령 정의는 cli/src/main.rs의 Knowledge 서브커맨드 묶음(상위 라우팅 145-149행, 액션 정의 1060-1189행)에 있고, 검색·임베딩·문서 동기화의 실제 처리는 데몬(component.daemon)과 임베딩 엔진(component.embedding-engine)이 수행한다. 코드가 사라져도 위 정책(맥락 부착 강제, 하이브리드 검색 기본값, docs 양방향 동기화, 위키 계층)만으로 재구현 가능하다.
