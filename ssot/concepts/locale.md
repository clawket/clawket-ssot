## 정의

Locale 은 Clawket 랜딩 사이트가 화면 카피를 보여줄 수 있는 "지원 언어" 하나를 뜻하는 개념이다. 사이트는 현재 20개 언어를 지원한다: 영어, 한국어, 일본어, 중국어(간체/번체 두 가지), 스페인어, 프랑스어, 독일어, 포르투갈어(브라질), 러시아어, 이탈리아어, 아랍어, 힌디어, 인도네시아어, 터키어, 베트남어, 태국어, 폴란드어, 네덜란드어, 스웨덴어다.

각 로케일은 세 가지 정보를 갖는다: (1) 언어 코드(예: `ko`, `pt-BR`, `zh-Hans`), (2) 드롭다운에 표시되는 사람이 읽는 이름(예: "한국어", "Português (Brasil)", "简体中文"), (3) 글쓰기 방향. 방향은 좌→우(ltr) 또는 우→좌(rtl) 중 하나이며, 20개 중 아랍어만 우→좌이고 나머지는 모두 좌→우다. 이 방향 값은 언어를 바꿀 때 문서 전체의 텍스트 흐름 방향을 정하는 데 쓰인다.

기본 로케일은 영어다. 방문자가 명시적으로 고르지 않았을 때 사이트는 브라우저가 알려주는 선호 언어 목록을 위에서부터 훑어 가장 먼저 매칭되는 지원 언어를 고른다. 이때 몇 가지 정규화 규칙이 있다: 중국어는 지역에 따라 간체/번체로 나눠 매핑하고(예: 중국 본토·싱가포르는 간체, 대만·홍콩·마카오는 번체, 그 외 일반 중국어는 간체로), 포르투갈어 계열은 모두 브라질 포르투갈어로 모은다. 매칭이 전혀 없으면 기본값인 영어로 떨어진다.

이웃 개념: 각 로케일은 [concept.dict](dict.md) 카피 사전 한 벌과 1:1로 대응한다(로케일 = 사전을 고르는 키). 로케일 목록·협상 규칙 자체는 [component.i18n](../components/i18n.md) 자체 i18n 엔진의 일부이고, [capability.switch-locale](../capabilities/switch-locale.md) 언어 전환 기능이 이 목록을 선택지로 노출한다.

## 엔티티 (DB)

이 개념은 데이터베이스에 저장되는 비즈니스 객체가 아니라, 랜딩 사이트 프런트엔드 코드 안에 박혀 있는 정적 상수 목록이다. 별도의 테이블·영속 저장소가 없다. 방문자가 고른 언어 선택만 브라우저 로컬 저장소(localStorage)에 보존되며, 이는 다음 방문 때 같은 언어를 다시 보여주기 위한 클라이언트 측 기억일 뿐 서버 상태가 아니다.

## API 표면

서버 API 가 없다. 로케일 목록과 판별·협상 동작은 전부 클라이언트(브라우저) 안에서 일어난다. 외부 통신은 발생하지 않는다.

## 불변식

- 지원 로케일 코드의 집합은 고정되어 있고(현재 20개), 코드와 표시 이름·방향은 1:1로 대응한다.
- 방문자 선택·저장값·URL 파라미터 어느 것도 지원 목록에 없는 코드는 받아들이지 않는다(유효성 검사를 통과하지 못하면 기본 협상 흐름으로 떨어진다).
- 매칭 실패 시 항상 기본 로케일(영어)로 안전하게 수렴한다 — "언어 없음" 상태는 존재하지 않는다.

## 구현 위치 (provenance)

지원 언어 목록과 각 언어의 표시 이름·방향, 그리고 브라우저 언어 협상 로직은 `landing/src/i18n/locales.ts` 한 파일에 모여 있다. 이 파일이 "어떤 언어를 지원하는가"의 단일 정의다. 코드가 사라져도, 위에 적은 20개 언어 목록·방향(아랍어만 우→좌)·기본값(영어)·중국어/포르투갈어 정규화 규칙만으로 동작을 재현할 수 있다.
